Pick the list that matches what you want to do next.

## Use devices from an agent

- [Choose a device](/simlock/docs/using-devices/choosing-a-device): ask for a model, a class such as `tablet`, or a range of OS versions.
- [Lease lifecycle](/simlock/docs/using-devices/lease-lifecycle): renew and release a lease, and what happens when you lose one.
- [Work with a leased device](/simlock/docs/using-devices/working-with-a-device): `simlock simctl`, `simlock adb` and the lease's environment variables.
- [Build and run your app](/simlock/docs/using-devices/build-and-run): build your app and run it on the leased device.
- [Physical devices](/simlock/docs/using-devices/physical-devices): lease an enrolled iPhone, iPad or Android phone.
- [Watch the screen](/simlock/docs/using-devices/watching-the-screen): see what a leased device shows.
- [agent-device](/simlock/docs/using-devices/agent-device): drive leased devices with agent-device.
- [Remote agents over HTTP](/simlock/docs/using-devices/remote-agents): lease from another machine.
- [Programmatic client](/simlock/docs/using-devices/programmatic-client): lease from Node.js code without the CLI.
- [When a lease fails](/simlock/docs/using-devices/errors): what each failure means and what to do.

## Run a worker

- [Run the daemon](/simlock/docs/worker/running-the-daemon): start, stop, start at login, logs, and where Simlock keeps its files.
- [Configuration](/simlock/docs/worker/configuration): change settings with `simlock config set`.
- [Capacity and warm pool](/simlock/docs/worker/capacity): how many devices the machine runs, and how to change it.
- [Runtimes and system images](/simlock/docs/worker/runtimes-and-images): install iOS runtimes and Android system images.
- [Cleanup and disk](/simlock/docs/worker/cleanup): when idle devices are shut down and deleted.
- [Enrol physical devices](/simlock/docs/worker/enrolling-physical-devices): add a phone or tablet.
- [Web console](/simlock/docs/worker/console): see devices, leases and the queue in your browser.
- [Monitoring](/simlock/docs/worker/monitoring): status, events and usage figures.
- [Troubleshooting](/simlock/docs/worker/troubleshooting): when something does not work.

## Run a fleet

- [When you need a gateway](/simlock/docs/gateway): what a gateway adds and what it costs.
- [Set up a gateway](/simlock/docs/gateway/setup), then [add workers](/simlock/docs/gateway/joining-workers) to it.
- [How requests are routed](/simlock/docs/gateway/routing): how the gateway picks a worker.
- [Access control](/simlock/docs/gateway/access-control): tokens for agents, operators and workers.
