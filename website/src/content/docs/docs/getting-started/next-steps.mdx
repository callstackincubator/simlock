## Use devices from an agent

- [Choosing a device](/simlock/docs/using-devices/choosing-a-device): ask for a model, a class such as `tablet`, or an OS version range.
- [Lease lifecycle](/simlock/docs/using-devices/lease-lifecycle): renew, release, and what happens when a lease is lost.
- [Working with a device](/simlock/docs/using-devices/working-with-a-device): `simlock simctl`, `simlock adb` and the lease's environment variables.
- [Physical devices](/simlock/docs/using-devices/physical-devices): lease an enrolled iPhone, iPad or Android phone.
- [Watching the screen](/simlock/docs/using-devices/watching-the-screen): see what a leased device shows.
- [agent-device](/simlock/docs/using-devices/agent-device): drive leased devices with agent-device.
- [Remote agents](/simlock/docs/using-devices/remote-agents): lease over HTTP from another machine.
- [Programmatic client](/simlock/docs/using-devices/programmatic-client): lease from Node.js code without the CLI.
- [Errors](/simlock/docs/using-devices/errors): what each failure means and what to do.

## Run a worker

- [Running the daemon](/simlock/docs/worker/running-the-daemon): start, stop, logs and where Simlock keeps its files.
- [Configuration](/simlock/docs/worker/configuration): change settings with `simlock config set`.
- [Capacity](/simlock/docs/worker/capacity): how many devices the machine runs, and how to change it.
- [Runtimes and images](/simlock/docs/worker/runtimes-and-images): install iOS runtimes and Android system images.
- [Cleanup](/simlock/docs/worker/cleanup): when idle devices are shut down and deleted.
- [Enrolling physical devices](/simlock/docs/worker/enrolling-physical-devices): add a phone or tablet to the pool.
- [Console](/simlock/docs/worker/console): the web view of devices, leases and the queue.
- [Monitoring](/simlock/docs/worker/monitoring): status, events and usage figures.
- [Troubleshooting](/simlock/docs/worker/troubleshooting): when something does not work.

## Run a fleet

- [When you need a gateway](/simlock/docs/gateway): what a gateway adds and what it costs.
- [Set up a gateway](/simlock/docs/gateway/setup), then [join workers](/simlock/docs/gateway/joining-workers) to it.
- [Routing](/simlock/docs/gateway/routing): how the gateway picks a worker.
- [Access control](/simlock/docs/gateway/access-control): tokens for agents, operators and workers.
