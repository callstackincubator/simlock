title: Lease your first device

---

import { Steps, Tabs, TabItem, Aside } from '@astrojs/starlight/components';

You lease a device from your terminal, install and launch an app on it, and give it back.

You need a machine where `simlock doctor` reports no missing tools for the platform you want. See [Install and check your machine](/simlock/docs/getting-started).

<Steps>

1. **Lease a device.**

   <Tabs syncKey="platform">
   <TabItem label="iOS">

   ```sh
   simlock lease --platform ios --device "iPhone 16" --detach
   ```

   </TabItem>
   <TabItem label="Android">

   ```sh
   simlock lease --platform android --device "Pixel 8" --detach
   ```

   </TabItem>
   </Tabs>

   If no free device fits, Simlock creates one. This can take a minute or more. Progress appears on stderr:

   ```text
   {"push":"progress","stage":"provisioning","etaMs":60500}
   {"push":"progress","stage":"booting","etaMs":60000}
   ```

   When the device is ready, Simlock prints the lease on stdout as one line of JSON. This is an iOS one:

   ```json
   {"device":{"id":"dev_0f6e2b4c-8d1a-4c3e-9b7f-5a2d1e8c4b90","driverDeviceId":"6B1F3A2C-9E47-4D8B-A0C5-2F7E1D93B468","spec":{"physical":false,"platform":"ios","model":"iPhone 16","osVersion":"18.4"},"address":"6B1F3A2C-9E47-4D8B-A0C5-2F7E1D93B468","physical":false,"mode":"full"},"environment":{"SIMLOCK_IOS_DEVICE_SET":"/Users/dana/.simlock/devices/ios"},"lease":{"id":"lse_3c9a7e10-52b4-4f6d-8e21-b07d4a9c6f35","deviceId":"dev_0f6e2b4c-8d1a-4c3e-9b7f-5a2d1e8c4b90","requesterId":"48213","ownerId":"48213","grantedAt":1792584000000,"ttlMs":900000,"ttlDeadline":1792584900000,"lastRenewedAt":1792584000000,"idChosenByRequester":false},"timing":{"estimatedProvisionMs":500,"estimatedBootMs":60000,"estimatedReclaimMs":34000,"estimatedReadyMs":60500},"role":"admin"}
   ```

   You need four fields:

   | Field | What it is |
   | --- | --- |
   | `lease.id` | The lease ID. You use it to renew and release. |
   | `device.address` | The device to point tools at: the simulator's UDID on iOS, the emulator's serial (such as `emulator-5554`) on Android. |
   | `lease.ttlDeadline` | When the lease ends if you do not renew it, in milliseconds since 1970. Here, 15 minutes after the lease started. |
   | `environment` | Variables to set for tools you run without `simlock` in front. |

2. **Install and launch your app.**

   A plain `xcrun simctl` or `adb` cannot see Simlock's devices. Put `simlock` in front of the command, and name your device by its `device.address`:

   <Tabs syncKey="platform">
   <TabItem label="iOS">

   ```sh
   simlock simctl install 6B1F3A2C-9E47-4D8B-A0C5-2F7E1D93B468 ./build/MyApp.app
   simlock simctl launch 6B1F3A2C-9E47-4D8B-A0C5-2F7E1D93B468 com.example.myapp
   ```

   </TabItem>
   <TabItem label="Android">

   ```sh
   simlock adb -s emulator-5554 install ./app/build/outputs/apk/debug/app-debug.apk
   simlock adb -s emulator-5554 shell am start -n com.example.myapp/.MainActivity
   ```

   </TabItem>
   </Tabs>

   <Aside type="caution" title="Always name the device">
   These commands also see other agents' devices. `booted`, or a missing `-s`, can reach a device that is not yours.
   </Aside>

   Simlock refuses commands that would break its devices, such as `simctl erase`, `simctl delete` or `adb kill-server`. See [Work with a leased device](/simlock/docs/using-devices/working-with-a-device).

3. **Release the device.**

   ```sh
   simlock release lse_3c9a7e10-52b4-4f6d-8e21-b07d4a9c6f35
   ```

   ```json
   {"leaseId":"lse_3c9a7e10-52b4-4f6d-8e21-b07d4a9c6f35"}
   ```

   Simlock deletes the simulator or emulator. The next lease gets a new one.

</Steps>

## Keep the lease longer

With `--detach`, the lease lasts 15 minutes unless you renew it. Renew before `ttlDeadline` to get another full TTL:

```sh
simlock lease renew lse_3c9a7e10-52b4-4f6d-8e21-b07d4a9c6f35
```

To ask for a longer TTL from the start, add `--ttl 1h` to `simlock lease`. The longest TTL is 4 hours by default.

## Tie the lease to your terminal or script

Leave out `--detach` and `simlock lease` keeps running after it prints the lease. It renews the lease for you, and releases it when you press Ctrl-C, when it gets `SIGTERM`, or when the process that started it exits.

## If the lease fails

Simlock prints the error on stderr as one line of JSON, and the exit code tells you the kind of failure:

```json
{"error":{"code":"RUNTIME_MISSING","message":"Runtime missing for ios 17.5"}}
```

| Code | Exit | What to do |
| --- | --- | --- |
| `UNKNOWN_MODEL` | 12 | This machine does not know the model name. Run `simlock catalog --platform ios` to see the models and OS versions you can lease. |
| `RUNTIME_MISSING` | 12 | The OS version is not installed. Pick an installed one from `simlock catalog`, or add `--allow-download`. |
| `NO_DRIVER` | 12 | The platform is not available on this machine. Run `simlock doctor`. |
| `QUEUE_TIMEOUT` | 10 | You set `--timeout` and no device freed up in time. |

If the command seems stuck, it is probably waiting in the queue. Without `--timeout`, it waits until a device frees up. The full list of errors is in [When a lease fails](/simlock/docs/using-devices/errors).

<Aside>
In a terminal, each `simlock` command gets its own identity, so the lease belongs to no particular agent. Agents get one identity per session. See [Connect your agent](/simlock/docs/getting-started/connect-your-agent).
</Aside>
