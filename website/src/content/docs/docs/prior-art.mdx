Simlock stands on other people's work. Thank you to the authors of these projects.

## serve-sim

By Evan Bacon. [github.com/EvanBacon/serve-sim](https://github.com/EvanBacon/serve-sim), Apache License 2.0.

Simlock includes a patched copy of serve-sim's screen capture for iOS simulators. It lets you watch a leased simulator's screen live in the console.

## scrcpy

By Romain Vimont and Genymobile. [github.com/Genymobile/scrcpy](https://github.com/Genymobile/scrcpy), Apache License 2.0.

Simlock includes the scrcpy server, version 5.0.1, unchanged. It lets you watch a leased Android emulator's or phone's screen live in the console.

## idevice

By Jackson Coxson. [github.com/jkcoxson/idevice](https://github.com/jkcoxson/idevice), MIT License.

Simlock uses a video setting from idevice when it streams a physical iPhone's screen. With it, the picture shows without tearing.

## agent-device

By Callstack. [github.com/callstack/agent-device](https://github.com/callstack/agent-device), MIT License.

Simlock's optional agent-device integration uses the `@agent-device/proxy` package, so you can drive leased devices with agent-device through a Simlock worker or gateway. See [agent-device](/simlock/docs/using-devices/agent-device).

## simslim

[github.com/mobai-app/simslim](https://github.com/mobai-app/simslim), MIT License.

simslim showed how to make an iOS simulator use far less memory by turning off background services it does not need for testing. Simlock's slim simulators (`--mode slim`) follow the same approach and use simslim's list of services to turn off.
