**Result:** your Node.js program leases a device, keeps the lease alive, runs commands on the device and gives it back, with no `simlock` commands.

| Import | For |
| --- | --- |
| `simlock/client` | Agents and tools that need devices: lease, renew, release, run commands, read the catalog and status. |
| `simlock/admin` | Operator tools: all of the above, plus every lease and device, tokens, cleanup, events, updating and stopping the daemon. |

Every call, option and answer: [Node client reference](/simlock/docs/reference/node-client).

## Before you start

- Node.js 22.13 or later.
- The package in your project:

  ```sh
  npm i simlock
  ```

- On the worker's own machine, the daemon is running. The client never starts it; `simlock daemon start`, or any `simlock` command, does.
- From another machine, the farm's URL and a token ([Use an existing farm](/simlock/docs/getting-started/existing-farm)).

## Connect

### On the worker's machine

```ts
import { homedir } from "node:os";
import { join } from "node:path";
import { connectSimlock } from "simlock/client";

const client = await connectSimlock({
  endpoint: join(homedir(), ".simlock", "daemon.sock"),
  principal: "build-bot-1",
});
```

- **`endpoint`** is `~/.simlock/daemon.sock`, or `$SIMLOCK_HOME/daemon.sock` when you set `SIMLOCK_HOME`. A gateway's is `~/.simlock/gateway/daemon.sock`. On Windows it is a named pipe: `\\.\pipe\simlock-` followed by the first 16 hex characters of the SHA-256 of the data folder's full path in lower case (for `~/.simlock`, of `c:\users\<you>\.simlock`).
- **`principal`** is your requester id, at most 256 characters with no control characters.

<Aside type="caution">
Give every agent or worker process its own `principal`. Clients that leave it out share the daemon's default id, and so share one lease.
</Aside>

### From another machine

```ts
import { connectSimlock } from "simlock/client";

const client = await connectSimlock({
  url: "https://simlock.example.com",
  token: process.env.SIMLOCK_TOKEN,
});
```

- **`url`** is the farm's origin, with no path: `https://`, or `http://` only for `127.0.0.1`, `[::1]` and `localhost`.
- **`token`**'s role is the session's role, and the token is the requester. It cannot go with `endpoint` or `principal`.
- **`signal`**, an optional `AbortSignal`, stops the connection attempt.

**Check:** `await client.listLeases()` resolves.

One client is one connection, and it never reconnects. A lost connection does not release your lease: connect again and carry on.

## Lease, use and release a device

This program leases an iPhone simulator, keeps the lease alive, installs and launches an app, and releases the device:

```ts title="lease-and-launch.mts"
import { homedir } from "node:os";
import { join, resolve } from "node:path";
import { connectSimlock, isSimlockError } from "simlock/client";

const client = await connectSimlock({
  endpoint: join(homedir(), ".simlock", "daemon.sock"),
  principal: "build-bot-1",
});

try {
  const grant = await client.requestLease(
    { platform: "ios", model: "iPhone 16", ttlMs: 10 * 60_000, timeoutMs: 5 * 60_000 },
    { onProgress: (progress) => console.error("waiting:", progress.stage) },
  );
  const { lease, device } = grant;
  console.error(`leased ${device.spec.model} ${device.driverDeviceId} as ${lease.id}`);

  // The client never renews for you. Renew every third of the TTL.
  const renewal = setInterval(() => {
    client.renewLease({ leaseId: lease.id }).catch((error) => console.error("renew failed:", error));
  }, lease.ttlMs / 3);
  client.onLeaseLost((push) => {
    if (push.leaseId === lease.id) console.error(`lease lost: ${push.reason}`);
  });

  try {
    const run = async (args: string[]) => {
      const { exitCode } = await client.exec(
        { leaseId: lease.id, tool: "simctl", args },
        { onOutput: ({ stream, chunk }) => (stream === "stdout" ? process.stdout : process.stderr).write(chunk) },
      );
      if (exitCode !== 0) throw new Error(`simctl ${args[0]} exited with ${exitCode}`);
    };
    await run(["install", device.driverDeviceId, resolve("build/Debug-iphonesimulator/MyApp.app")]);
    await run(["launch", device.driverDeviceId, "com.example.myapp"]);
  } finally {
    clearInterval(renewal);
    await client.releaseLease({ leaseId: lease.id });
  }
} catch (error) {
  if (!isSimlockError(error)) throw error;
  console.error(`${error.code}: ${error.message}`);
  process.exitCode = 1;
} finally {
  await client.close();
}
```

Run it with a TypeScript runner, for example `npx tsx lease-and-launch.mts`.

**Check:** the app opens on the simulator, and `simlock status` shows no lease for `build-bot-1` once the program ends.

- `requestLease` takes the same choices as `simlock lease`, under the names `platform`, `model` or `class`, `osVersion`, `mode`, `imageTag`, `baseline`, `physical`, `ttlMs`, `timeoutMs`, `noWait`, `allowDownload`, `leaseId` and `metadata`. What each choice means: [Lease a specific model or OS](/simlock/docs/using-devices/lease-a-specific-device).
- `exec` runs `simctl` or `adb` (or `devicectl` on a physical iPhone or iPad). You may leave the device out; Simlock adds the lease's device, and refuses a command that names another one with `PASSTHROUGH_REFUSED`. Use absolute paths: the command runs in the daemon's process, not in your program's working folder.
- `close()` closes the connection. It does not release your leases.

## Stop waiting

Pass an `AbortSignal` to stop waiting for a device:

```ts
const controller = new AbortController();
setTimeout(() => controller.abort(), 60_000);
const grant = await client.requestLease({ platform: "android", class: "tablet" }, { signal: controller.signal });
```

- Aborting takes the request out of the queue and rejects with `CANCELLED`.
- If Simlock was already creating or starting the device, it finishes, and the client releases the device as soon as it is granted.
- An abort after the grant does nothing. Release the lease yourself.

## Handle errors

Every failure the daemon reports is a `SimlockError` with a `code` and a `message`, the same codes the CLI prints. Check for it with `isSimlockError`:

```ts
try {
  await client.requestLease({ platform: "ios", model: "iPhone 16", noWait: true });
} catch (error) {
  if (!isSimlockError(error)) throw error;
  if (error.code === "NO_CAPACITY") console.error("No device is free right now; try again later.");
  else if (error.code === "REQUESTER_ALREADY_LEASED") console.error(error.message);
  else throw error;
}
```

The message of `REQUESTER_ALREADY_LEASED` names the lease you already hold.

## Use the admin client

`simlock/admin` gives an operator tool control of the whole daemon, and has every method of `simlock/client` too.

```ts
import { readFile } from "node:fs/promises";
import { homedir } from "node:os";
import { join } from "node:path";
import { connectSimlockAdmin } from "simlock/admin";

const home = join(homedir(), ".simlock");
const admin = await connectSimlockAdmin({
  endpoint: join(home, "daemon.sock"),
  credential: (await readFile(join(home, "admin.token"), "utf8")).trim(),
  principal: "ops-dashboard",
});

const leases = await admin.list({ kind: "leases" });
console.log(leases);
await admin.close();
```

The `credential` is the contents of `~/.simlock/admin.token`, which the daemon writes with a new secret each time it starts (read it again after a restart), or the secret of an operator token. From another machine, pass `url` and an operator `token` instead; `connectSimlockAdmin` takes no `credential` with `url`.

<Aside type="caution">
The admin credential lets a program release every agent's lease and stop the daemon. Keep it away from agents; give them `simlock/client`.
</Aside>

## When it fails

| Code | Cause | Fix |
| --- | --- | --- |
| `TypeError` (thrown before anything is sent) | A bad `url` or `token`, or `url` mixed with `endpoint`, `ipc`, `connection` or `principal`. | Fix the options. |
| `REMOTE_UNREACHABLE` | Nothing answers at the URL, no answer in 10 seconds, or a proxy or older farm answers with a status such as 502 or 404. | Check the URL and the farm. |
| `UNAUTHENTICATED` | The farm refuses the token, or it was revoked while connected; every later call fails too. | Use a valid token and connect again. |
| `FORBIDDEN` | The token's role may not do this, such as a worker join token. | Use an agent or operator token. |
| `ADMIN_AUTHENTICATION_FAILED` | A missing or wrong admin `credential`. | Read `admin.token` again after a daemon restart. |
| `DAEMON_CONNECTION_LOST` | The daemon stopped, the connection dropped, or the farm sent no ping for 45 seconds. Every call in progress fails. | Connect again. Your lease is still yours until its deadline. |
| `CANCELLED` | You aborted `requestLease`. | — |
| `REQUESTER_ALREADY_LEASED` | This `principal` or token already holds a lease. | Use it, release it, or give each process its own `principal`. |
| `BAD_REQUEST` | A bad request field, such as a `principal` over 256 characters. | Fix the field the message names. |

All codes: [Errors reference](/simlock/docs/reference/errors).
