Find what you see, then follow the link. For any error code, [Errors and exit codes](/simlock/docs/reference/errors) lists them all. On the worker, start with `simlock daemon logs` and `simlock doctor`: see [Read the log first](/simlock/docs/troubleshooting/worker#read-the-log-first).

## Leasing a device

| What you see | Go to |
| --- | --- |
| `simlock lease` stays at `queued` | [The lease waits and never starts](/simlock/docs/troubleshooting/lease-fails#the-lease-waits-and-never-starts) |
| `QUEUE_TIMEOUT` or `NO_CAPACITY` | [The lease waits and never starts](/simlock/docs/troubleshooting/lease-fails#the-lease-waits-and-never-starts) |
| `REQUESTER_ALREADY_LEASED`, `LEASE_ID_TAKEN` | [You already hold a lease](/simlock/docs/troubleshooting/lease-fails#you-already-hold-a-lease) |
| `UNKNOWN_MODEL`, `RUNTIME_MISSING`, `MODE_UNAVAILABLE`, `NO_DRIVER` | [The machine cannot give you that device](/simlock/docs/troubleshooting/lease-fails#the-machine-cannot-give-you-that-device) |
| A baseline lease fails: `UNKNOWN_BASELINE`, `BASELINE_STALE`, `BASELINE_MISMATCH` | [The machine cannot give you that device](/simlock/docs/troubleshooting/lease-fails#the-machine-cannot-give-you-that-device) |
| `ADMISSION_DENIED`, `ADMISSION_FAILED` | [The gateway refused the request](/simlock/docs/troubleshooting/lease-fails#the-gateway-refused-the-request) |
| `PROVISION_FAILED` | [The device does not start](/simlock/docs/troubleshooting/lease-fails#the-device-does-not-start) |
| Exit 14, a `lease-lost` line, or `UNKNOWN_LEASE` | [You lost the lease](/simlock/docs/troubleshooting/lease-fails#you-lost-the-lease) |
| `simlock adb` or `simlock simctl` refuses a command, or `EXEC_TIMEOUT` | [A command on the device fails](/simlock/docs/troubleshooting/lease-fails#a-command-on-the-device-fails) |
| `DAEMON_STARTUP_FAILED`, `DAEMON_CONNECTION_LOST`, `PROTOCOL_VERSION_UNSUPPORTED` | [The CLI cannot reach the daemon](/simlock/docs/troubleshooting/lease-fails#the-cli-cannot-reach-the-daemon) |
| `401`, `404` or `409` from the HTTP API | [Over HTTP](/simlock/docs/troubleshooting/lease-fails#over-http) |
| A real phone is never granted | [Lease a real iPhone or Android phone](/simlock/docs/using-devices/lease-a-phone) |
| MCP tools answer `NO_LEASE`, or the lease ended under the agent | [Give your agent the MCP server](/simlock/docs/getting-started/mcp-server) |
| agent-device reports an error | [Drive an app's UI with agent-device](/simlock/docs/using-devices/agent-device) |
| A tunnel or your own adb cannot reach the device | [Use your own adb and tools through a tunnel](/simlock/docs/using-devices/tunnels) |
| A CI job leaves devices leased, or a full farm fails jobs | [Run e2e tests from CI](/simlock/docs/using-devices/ci) |
| The screen does not show, or the picture stops | [Watch a device's screen](/simlock/docs/using-devices/watch-the-screen) |
