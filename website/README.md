# Simlock website

The site at https://callstackincubator.github.io/simlock/: the home page, a 404 page and the
docs, in the Callstack product look. Astro and Starlight, its own package (run everything from
this folder), deployed to GitHub Pages by `.github/workflows/website.yml` on every push to
`main` that changes `website/`, `docs/*.md`, `src/`, `package.json` or `pnpm-lock.yaml` (the HTTP API
reference is built from the code); a pull request that changes them builds it without deploying.

The look, the scenes and the words are in [BRAND.md](../docs/internal/BRAND.md). The end-user
docs live only here, in `src/content/docs/docs/`, one `.mdx` page each; the sidebar is in
`astro.config.mjs`.

## Commands

Node 24 (anything from 22.18 works: `pnpm og` and the configs import `.ts` files directly).

```bash
pnpm install      # and the repo root's, which `dev`, `build` and `check` use to write public/openapi.json
pnpm dev          # http://localhost:4321
pnpm build        # static site in dist/
pnpm preview
pnpm check        # astro check: types in .astro and .ts files
pnpm exec playwright-core install chromium   # once, for pnpm og (or have Google Chrome)
pnpm og           # public/og-image.jpg, banner.jpg, favicon.svg, favicon-32.png, apple-touch-icon.png
```

`dev`, `build` and `check` first run `pnpm openapi` at the repo root, which writes the gitignored
`public/openapi.json` that `starlight-openapi` renders under Reference → HTTP API reference and the site serves at
`/openapi.json`. `node scripts/check-openapi.mjs` checks the built site.

`public/` is generated by `pnpm og` and committed. Re-run it after changing `content.ts`, `brand.ts`,
`og/og.html`, the hero's `story.ts` or the fleet scene.

## Where things go

| Path                                                                           | What it is                                                                                        |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| `src/site/content.ts`                                                          | Product facts and all copy                                                                        |
| `src/site/brand.ts`                                                            | The accent; injected as CSS variables everywhere                                                  |
| `src/site/meta.ts`                                                             | Page titles: `Name: subtitle` on home, `Page                                                      | Name` everywhere else; never write a separator by hand |
| `src/pages/index.astro`                                                        | Home page layout; reorder sections with `order`                                                   |
| `src/components/home/Hero.astro`, `hero.ts`, `story.ts`                        | The hero: copy, then a two-step stage (one machine, then a fleet of them behind a gateway); its animation and data |
| `src/components/home/ConsoleView.astro`, `console-view.ts`, `console-story.ts` | The drawn console in the Console section                                                          |
| `src/components/site/dither.ts`                                                | Dithered scenes: `fleet` (the signature), `hollow` (404), `flow`, `mark`                          |
| `src/components/site/`                                                         | Nav, Lockup, Mark, Window, CodeBlock, CopyCommand, Tabs, Marquee, Faq, PixelIcon, Closing, Footer |
| `src/pages/404.astro`                                                          | Not found, on the `hollow` scene                                                                  |
| `src/pages/robots.txt.ts`                                                      | robots.txt from the site URL                                                                      |
| `src/layouts/Site.astro`                                                       | Head, SEO and social tags for pages outside the docs                                              |
| `src/components/starlight/`                                                    | Docs header lockup, header links, footer, dark default                                            |
| `src/styles/`                                                                  | `landing.css` (tokens, building blocks), `theme.css` and `docs.css` (docs)                        |
| `src/routeData.ts`                                                             | Docs: clean canonicals, descriptions from the first paragraph, breadcrumbs                        |
| `og/og.html`, `scripts/og.mjs`                                                 | Social card, banner and icons                                                                     |
| `ec.config.mjs`                                                                | Docs code block colours                                                                           |
